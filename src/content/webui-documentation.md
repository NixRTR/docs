# WebUI — Documentation Link

The WebUI provides an in-app link to this documentation site.

## Location

In the WebUI sidebar, under **External Links** or at the bottom of the sidebar, click **Documentation**. It opens the project documentation (GitHub Pages or the same site you are reading now) in a new browser tab.

## Purpose

- **Quick access** — Open the docs without leaving the router’s IP or bookmarking a separate URL.
- **Same content** — The link points to the same documentation (installation, configuration, WebUI pages, verification, upgrading) that is available at [https://NixRTR.github.io/docs/](https://NixRTR.github.io/docs/).

**Note:** Documentation site paths (e.g. `/webui/dns`, `/configuration/cake`) are for this docs site. Inside the WebUI app, the same features live under different paths (e.g. `/settings/dns`, `/settings/cake`). Use the sidebar in the WebUI to navigate the app, and this site to read about each feature.
